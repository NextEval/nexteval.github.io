NEXTEVAL SOLVER / PYTHON

Solver Python API

Call solve or minimize from Python to optimize an objective. This is the Solver library interface, not a model provider API or a hosted Bench service.

Quick start Model provider setup solve Options DFOResult Custom agents

Quick start

For installation, complete examples and harness choices, start with the Solver User Guide. This reference targets Solver 1.0.0 at cb58fd7; its runtime dependency is NumPy.

python -m pip install \
  "git+https://github.com/NextEval/nexteval.git@cb58fd74901de2476fe15b60ee4cfc993ca04095"

Configure a tool-calling model as described below, then run:

import numpy as np
from nexteval import solve

result = solve(
    lambda x: float(x @ x),
    np.array([2.0, -1.0, 0.5]),
    options={
        "execution_mode": "task",
        "model": "env",
        "maxfev": 80,
        "seed": 7,
        "trace": "off",
    },
)

print(result.x, result.fun, result.nfev)
print(result.status, result.message)

Model provider setup

The model provider API supplies model responses to the agent. Its endpoint, credentials, and model ID are separate from the Solver Python API above. An external harness may manage this connection itself.

See the User Guide's provider setup for explicit OpenAI-compatible and Anthropic-compatible clients, or model and harness for external sessions.

model="env" uses an Anthropic-compatible provider. Set your endpoint, model ID, and token in the local environment; the values below are placeholders.

export ANTHROPIC_BASE_URL="https://your-compatible-endpoint/v1"
export ANTHROPIC_MODEL="your-model-id"
export ANTHROPIC_AUTH_TOKEN="your-token"

The endpoint must support tool calls. Keep credentials out of code and trace files. This website does not receive your credentials or run the solver.

OpenAI-compatible and Azure providers use their own configurations. External harnesses may manage their own authentication. See provider configuration and the harness support matrix.

solve

solve(fun, x0, options=None) -> DFOResult
fun
A callable accepting a one-dimensional NumPy array and returning a scalar objective value. The solver minimizes it as an opaque oracle.
x0
A nonempty, finite, one-dimensional starting point.
options
A mapping or SolverOptions. The default execution mode is task; a model configuration is required.

Task mode preserves one runner session across model and tool turns. It is not a fresh agent launch per function evaluation.

Common options

maxfev
The total function-evaluation ceiling, including the initial point and failed objective calls. This is separate from the model-token budget.
model
"env", a provider specification, or a compatible model client.
execution_mode
"task" for a whole-session runner; "stepwise" for a policy invoked at each decision boundary.
seed
The solver's random seed. It does not guarantee deterministic model-provider responses.
trace
"off", "summary", "trajectory", "debug", or "develop". Persistent tracing is opt-in.
runner_options
Settings for the built-in task runner, such as token limits, compaction, and retries.

All solver options ↗

DFOResult

A dictionary with attribute access, similar to SciPy's OptimizeResult.

x / fun
The best valid recorded point and its objective value.
nfev
The actual objective-call count recorded in the evaluation ledger.
status / message
The numeric termination status and its human-readable explanation.
success
The solver completion flag. It does not, by itself, establish a valid benchmark trial.
completion_quality
Completion and protocol quality. Inspect this together with comparable_under_budget before pooling results.
trace_path
The trace location when persistent tracing is enabled.

Custom agents

Use the lower-level minimize entry point to supply a runner, policy, model, or toolset.

minimize(
    fun, x0, args=(), *,
    policy=None, advisor=None, model=None,
    toolset=None, callback=None, runner=None,
    options=None,
) -> DFOResult

A runner.run(task, gateway) owns a complete task. A policy.decide(observation, context) owns a stepwise decision. Both use the same protected objective ledger and budget accounting.
