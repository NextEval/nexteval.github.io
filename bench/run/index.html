Candidate status

Pre-release candidate, not provider-certified or genuine-CLI-certified. Package 0.1.0rc1 is not a PyPI release. Local checks and documentation tests do not establish account access, a working installed native CLI, effective thinking controls, or benchmark acceptance.

This named-dataset workflow evaluates harness + model + configuration. OptiProfiler owns problems, features and numerical profiles; pinned Harbor owns each full agent session and container; Bench owns the adapter and evidence contract. The agent receives a budgeted callable objective, x0, maxfun and common instructions, not NextEval Solver's numerical toolkit. Historical assisted v1 and legacy toy runs are different protocols.

Installation is pinned to candidate commit 8dca62ccc550031517094a985ad4af0830bac6d8, available for review but not a tagged release. Maintainer release approval and genuine native CLI/provider acceptance remain pending. Do not substitute a moving branch or treat this page as a run receipt.

Installation

Use Python 3.12 or newer and a working local Docker daemon on a reviewed macOS or Linux research host. These commands use Bash. Keep the Bench environment separate from Solver and the website; neither is required to run this path.

git clone https://github.com/NextEval/nexteval-bench.git
cd nexteval-bench
git checkout --detach 8dca62ccc550031517094a985ad4af0830bac6d8
python3 -m venv .venv
source .venv/bin/activate
python -m pip install .
python -m pip check
nexteval-bench --version
docker build -t nexteval-bench-agent:scientific-v1 images/scientific

Stop on any failed command. Installation and image building may download dependencies, but do not run a model or objective. Review the host firewall and image first. The image must not contain the private evaluator, problem library, credentials or experiment records. Execution resolves its tag to a local content ID; changing the image invalidates the matching smoke treatment.

Exact treatment

The example selects the existing Claude Code API route. Set the four named variables locally to reviewed values before copying the setup block. BENCH_CREDENTIAL_FILE is an absolute path to an existing valid private credential file outside both output directories, never a credential value. Do not create a fake credential to make preflight pass, print credentials, put them in command arguments, or upload them to this website.

: "${BENCH_MODEL:?Set the exact reviewed anthropic/model ID}"
: "${BENCH_CLI_VERSION:?Set the exact reviewed Claude Code version}"
: "${BENCH_BASE_URL:?Set the reviewed HTTPS API endpoint}"
: "${BENCH_CREDENTIAL_FILE:?Set an existing absolute private credential-file path}"
TREATMENT=(
  --agent claude-code --model "$BENCH_MODEL"
  --agent-version "$BENCH_CLI_VERSION" --thinking disabled
  --auth api --base-url "$BENCH_BASE_URL"
  --credential-file "$BENCH_CREDENTIAL_FILE"
  --image nexteval-bench-agent:scientific-v1
  --session-timeout 1000 --research-network
)
DATASET="nexteval-u5-perturbed@1"
SMOKE_DIR="$HOME/nexteval-local/smoke-reviewed-treatment"
RUN_DIR="$HOME/nexteval-local/run-reviewed-treatment"

Keep the same Bash session for later blocks. Both output directories must be new and evaluator-private; preserve existing attempts rather than overwriting them. Disabled thinking is a request, not proof of provider behavior. If native records use another canonical model ID, explicitly review and add --reported-model to this shared treatment before preflight, smoke and run; never infer or silently accept an alias.

Codex is the other implemented named-CLI adapter, selected by --agent codex; implementation alone does not admit a provider treatment. Changing harness, model, version, reasoning, authentication or endpoint creates another treatment requiring its own review and smoke. For subscription authentication use the selected harness's valid private login source, --auth subscription, and omit --base-url. A CLI login is not a generic API key; no route silently falls back to a different paid API.

No-call checks

Run these checks before seeking authorization for real-agent work. They make no model calls or objective evaluations. They are not an authenticated provider smoke.

nexteval-bench doctor --image nexteval-bench-agent:scientific-v1
nexteval-bench datasets list
nexteval-bench datasets show "$DATASET"
nexteval-bench datasets verify "$DATASET"
nexteval-bench preflight "${TREATMENT[@]}"
nexteval-bench run --dataset "$DATASET" "${TREATMENT[@]}" \
  --n-concurrent 1 --output "$RUN_DIR" --dry-run
doctor
Checks installed numerical dependencies, Docker and the image, not provider authentication.
preflight
Checks dependencies, explicit local auth route and credential-file format/permissions, native adapter hooks, Docker and image identity. It reads the local credential source without emitting it. local_ready=true and model_calls=0 leave provider authentication, model access, installed container CLI version and reasoning-control acceptance unverified. It launches no agent or container and refreshes no login.
--dry-run
Checks the frozen problem-library source and prints a plan without Docker, model calls, objective evaluations or an experiment output directory. It does not validate account access or credential contents. Removing this flag alone is not authorization to execute.

The selected u5 candidate means dimensions 1 through 5, not exactly dimension 5. Its frozen plan expects 92 problems × 10 repetitions = 920 agent identities, each with a 50*n objective budget. Those are expected counts, not materialized attempts or scores. The paired real COBYQA reference is separate from the agent denominator and is never a fallback.

Separately authorized smoke

Stop here until this exact real-agent smoke is explicitly authorized. The following command contacts a model and may incur charges or subscription usage. No earlier check, page load or copy action invokes it. Do not run a replacement smoke automatically when validation fails.

# Run only after separate authorization for this exact treatment.
nexteval-bench smoke "${TREATMENT[@]}" --output "$SMOKE_DIR"

Acceptance requires exactly six successful objective evaluations in one native tool-bearing session on the private two-dimensional plain smoke problem. Ledger queries, exported observations and retained OptiProfiler clean histories must agree. Retain $SMOKE_DIR/smoke-receipt.json together with the original trials/<trial_id>/, receipt-bound inventory, native model/version records and confirmed cleanup. A copied receipt alone, CLI exit zero or a positive evaluation count is insufficient.

The existing offline validate_smoke gate rechecks this exact source/framework, treatment, image and retained evidence before admission. Hash binding is not independent provider attestation. A source, CLI or configuration change needs separate review and authorization, not receipt editing or an automatic paid retry. Passing smoke is not a benchmark score.

Separately authorized run

Dataset execution needs its own authorization after the matching smoke passes. This is a potentially substantial real-model run, not part of local preflight or a consequence of passing smoke. Inspect the expected denominator and private output path first.

# Run only after separate authorization for the dataset execution.
nexteval-bench run --dataset "$DATASET" "${TREATMENT[@]}" \
  --n-concurrent 1 --output "$RUN_DIR" \
  --smoke-receipt "$SMOKE_DIR/smoke-receipt.json"

--n-concurrent is OptiProfiler's top-level n_jobs, not an API rate limit or a second Harbor pool. Each agent solver invocation owns an independent native session, container and ledger. The requested 1000-second allowance excludes setup. Ordinary audited wall timeouts remain numerical failures, not retry requests; provider/authentication/cleanup errors are not generic ordinary timeouts.

Do not silently change routing or networking to unblock a run. The existing automatic oracle transport is Unix on Linux and TCP on macOS; this page adds no transport or scaffold. --research-network acknowledges supervised single-tenant research networking, not hostile-submission isolation or hosted security acceptance. Retain partial runs and all originals when execution stops.

Saved evidence and blank scores

After workers have stopped, inspect a quiescent evaluator-owned root. These commands inspect saved evidence without model calls, objective evaluations or scheduling continuations.

nexteval-bench status "$RUN_DIR"
nexteval-bench artifacts check "$RUN_DIR"
Expected
The frozen plan's identity denominator, not a count inferred from directories. Invalid or conflicting plans yield unknown (null) counts.
Materialized
Enumerated trial entries and parseable identities, including incomplete attempts. Attempts are not unique identities; duplicate attempts put all copies into review.
Evidence-eligible terminal
eligible_numerical_terminal requires rechecked numerical evidence, native identity and configuration, hash-bound artifacts and cleanup. Eligibility is not model success or publication.
Pending or review
infra_pending retains incomplete attempts and infrastructure or operator terminations; unknown_review retains missing or unsafe evidence, unknown errors, duplicates and no-evaluation records. automatic_retry=false; no generic no-evaluation permit is admitted.
Archived
An independent accepted archive receipt bound to eligible identities and current evidence. Files, HDF5s and PDFs alone do not establish it.
Published
An independent accepted publication receipt, not a runtime flag. This offline reader does not fetch the destination, authenticate a publisher or establish remote availability.

coverage_complete requires one eligible attempt for every expected identity without extras or invalid attempts. It does not establish HDF5 assembly, archive, publication or successful model outcomes. Expected, materialized, evidence-eligible, archived and published counts must remain distinct.

Numerical eligibility also requires both finalized cancellation-origin and original-agent-execution receipts. Missing either or both remains review-only, even after rehashing the artifact inventory. This reader adds no automatic legacy admission policy: preserve older records for separate exact-source review, without rewriting or rerunning them.

Incomplete scores stay blank. Missing or unaccepted results are not zero scores or fabricated numerical success. Native OptiProfiler histories are the numerical authority; an observed incumbent does not replace clean scoring history. Changed source or CLI versions remain separate generations (split_epochs), not one homogeneous comparison. Keep raw logs, model content, credentials and evaluator-private histories out of public exports.
